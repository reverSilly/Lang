定义：`new`+`[prototype-Expr]`

从值的原型返回对应的值对象。

创建出的协程是一个独立的值，互相不存在从属关系。

值对象的求值可以被暂停并切换到其他求值。

若a中调用了b，则a将被挂起，b协程将被恢复继续求值。本协程中的调用表达式称为本协程的挂起点。

若a在最后一个挂起点被恢复，则当求值完毕后，会自动返回到调用a的协程，传递的值为 `[Expr]` 。

调用语法：`闭包表达式`@`[Expr]`

协程调用表达式的值即为本协程被恢复时传入的值。

若一个协程内部没有调用其他协程，或者调用的协程都是函数，或者所有的挂起点都可以静态的确定，那么这个协程被称为函数。函数在编译时会得到特殊的优化。

```
new^{a:=\^@;val:=a.0+a.1}.val@(1,2) !-值为3!
```


例子1：
```
!-定义!
x:=new^(\^@+1);
!-实例化!
res:=x@1;
!-res值为2!
```


例子2：
```
inc_sq:=
new^{
        a:=arguments:lvalue integral;
        a=$a+1;
        value:=$a*$a;
    }.value;
a:=allocate integer=114514;
res:=inc_sq@a;
!-res为114515*114515，a为114515!
```
