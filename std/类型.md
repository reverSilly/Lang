一个值一定拥有一个类型，
一个值的类型在值被创建后就不能再改变。

每一个 `作用域表达式` 都会创造一个新的右值类型。

所有的类型都继承自 `object` 。

继承的子类自动定义一个到父类的转换。

一个类型也是一个值，拥有类型 `type` 。

```
overload type as type:=
{
    extends as closure[type[()],types];
    type as type;
    size as integer;
}
overload type as closure[type,value]:=__built_in__
```
