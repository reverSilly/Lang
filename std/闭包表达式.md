定义语法：`[`+ `lvalue-Expr` ? +`]` + `Expr`

实例化语法：`[`+`Expr`+`]`+`模板表达式`

值为一个可实例化的模板，可用于实例化。该表达式值为右值。

实例化时，将实际参数赋值给 `lvalue-Expr` ，并代入到右侧 `Expr` 中并返回。

左侧 `lvalue-Expr` 中定义的标识符和值仅在右侧 `Expr` 中有效。右侧 `Expr` 为一个单独的作用域。

语言保证一个闭包表达式的值一定是 `POD` 的。


例子1：
```
//定义
x:=([a:=allocate 0]$a+1)
//实例化
res:=x[1]
//res值为2
```


例子2：
```
inc_sq:=
[a](x:=$a+1,
    a=$x,
    x*x)[-1]
a:=allocate 114514
res:=inc_sq[a]
//res值为114515*114515，a值为114515
```
