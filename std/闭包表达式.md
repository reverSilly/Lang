定义语法：`[`+ `lvalue-Expr` ? +`]` + `Expr`

实例化语法：`[`+`Expr`+`]`+`闭包表达式`

值为一个可实例化的模板，可用于实例化。该表达式值为右值。

实例化时，将实际参数赋值给 `lvalue-Expr` ，并代入到右侧 `Expr` 中并返回。

左侧 `lvalue-Expr` 中定义的标识符和值仅在右侧 `Expr` 中有效。

语言保证一个闭包表达式的值一定是 `POD`,`constant`的。

同时，允许使用一种简便方式：使用 `?` 占位符。

所有被 `?` 占据的位置都将成为一个参数，可以被按出现的顺序实例化闭包。

```
(?+?)[1,2]; //值为3
```


例子1：
```
//定义
x:=([a as integer:=$allocate integer]($a+1));
//实例化
res:=x[1];
//res值为2
```


例子2：
```
inc_sq:=
[a as integer]
{
    x:=a+1,
    a=$x,
    value:=x*x
}.value;
a:=allocate integer=114514;
res:=inc_sq[a];
//res值为114515*114515，a值为114515
```
