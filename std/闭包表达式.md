定义语法：`[`+ `[Expr]` ? +`]`

实例化语法：`闭包表达式`+`@`+`[Expr]`

值为一个可实例化的模板，可用于实例化。该表达式值为右值。

闭包中的 `[Expr]` 中可以使用 `?` 标识符，代指下一个输入的值。

闭包中允许使用 `yield` 关键字来丢出一个值，返回到调用者处作为本次实例化的值。

语法： `yield`+`[Expr]`



实例化时，将 `[Expr]` 的值代入闭包中第一个未被代入的 `?` ，并等待闭包 `yield` 出一个值或整个闭包求值完毕。

若在实例化前仍需要输入值，则 #undone#。

语言保证一个闭包表达式的值一定是 `POD`,`constant`的。


```
[?+?]@(1,2) //值为3
```


例子1：
```
//定义
x:=[(? as integer)+1];
//实例化
res:=x@1;
//res值为2
```


例子2：
```
inc_sq:=
[{
    a:=(? as lvalue integer);
    x:=a+1;
    a=$x;
    value:=x*x;
}.value];
a:=allocate integer=114514;
res:=inc_sq@a;
//res值为114515*114515，a值为114515
```
