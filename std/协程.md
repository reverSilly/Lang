定义：`[`+ `[Expr]` ? +`]`

每一个协程都是一个独立的值，互相不存在从属关系。

协程定义出来默认是挂起的。

可以通过协程调用表达式来挂起这一个值，转移到协程中。

调用语法：`[Expr]`@`闭包表达式`

值为一个可实例化的模板，可用于实例化。该表达式值为右值。

语言保证一个闭包表达式的值一定是 `POD`,`constant`的。


/*
```
[?+?]@(1,2) //值为3
```


例子1：
```
//定义
x:=[(? as integer)+1];
//实例化
res:=x@1;
//res值为2
```


例子2：
```
inc_sq:=
[{
    a:=(? as lvalue integer);
    x:=a+1;
    a=$x;
    value:=x*x;
}.value];
a:=allocate integer=114514;
res:=inc_sq@a;
//res值为114515*114515，a值为114515
```
