定义：`new`+`[Expr]`

返回一个协程，可以被调用求值。

每一个协程都是一个独立的值，互相不存在从属关系。

`[Expr]` 不会被立即求值，而是默认被挂起。`[Expr]`中可以访问外部的值，在协程创建时外部的值将作为协程的参数，在创建后不可改变。第一次被恢复时传入的值可以使用 `arguments` 来访问。

若a协程中通过协程调用表达式调用了b协程，则a协程将被挂起，b协程将被恢复继续求值。本协程中的调用表达式称为本协程的挂起点。

协程最后一次挂起后若再次被恢复，则当求值完毕后，将会自动地返回到上一个协程，值为 `[Expr]` 。

调用语法：`[Expr]`@`闭包表达式`

协程调用表达式的值即为本协程被恢复时传入的值。

若一个协程内部没有调用其他协程，或者调用的协程都是函数，或者所有的挂起点都可以静态的确定，那么这个协程被称为函数。函数在编译时会得到特殊的优化。

```
(1,2)@[arguments.0+arguments.1] //值为3
```


例子1：
```
//定义
x:=new(arguments:integral+1);
//实例化
res:=1@x;
//res值为2
```


例子2：
```
inc_sq:=
new
    {
        a:=arguments:lvalue integral;
        a=$a+1;
        value:=$a*$a;
    }.value;
a:=allocate integer=114514;
res:=a@inc_sq;
//res为114515*114515，a为114515
```
