定义：`[`+ `[Expr]` ? +`]`

每一个协程都是一个独立的值，互相不存在从属关系。

`[]` 内部同时是一个对象，不可访问外部。

协程定义后默认被挂起。第一次被恢复时传入的值可以使用 `\_arguments` 来访问。

可以通过协程调用表达式来挂起此值的求值，恢复协程中的值求值。

调用语法：`[Expr]`@`闭包表达式`

协程调用表达式的值即为本协程被恢复时传入的值。

若一个协程内部没有调用其他协程，或者调用的协程都是函数，那么这个协程被称为函数。函数会得到特殊的优化。

```
(1,2)@[\_arguments.0+\_arguments.1] //值为3
```


例子1：
```
//定义
x:=[\_arguments:integral+1];
//实例化
res:=1@x;
//res值为2
```


例子2：
```
inc_sq:=
[
    result:=
    {
        a:=\_arguments:lvalue integral;
        a=$a+1;
        value:=$a*$a;
    }.value
];
a:=allocate integer=114514;
res:=a@inc_sq;
//res为114515*114515，a为114515
```
