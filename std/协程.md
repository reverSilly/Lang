定义：`[`+ `[Expr]` ? +`]`

每一个协程都是一个独立的值，互相不存在从属关系。

`[]` 内部不可访问外部的标识符。

协程定义后默认被挂起。第一次被恢复时传入的值可以使用 `arguments` 来访问。

协程调用表达式会挂起此值的求值，恢复协程中的值的求值。本协程中的调用表达式称为本协程的挂起点。

协程最后一次挂起后若再次被恢复，则当求值完毕后，将会自动地返回到上一个协程，值为 `[Expr]` 。

调用语法：`[Expr]`@`闭包表达式`

协程调用表达式的值即为本协程被恢复时传入的值。

若一个协程内部没有调用其他协程，或者调用的协程都是函数，或者所有的挂起点都可以静态的确定，那么这个协程被称为函数。函数在编译时会得到特殊的优化。

```
(1,2)@[arguments.0+arguments.1] //值为3
```


例子1：
```
//定义
x:=[arguments:integral+1];
//实例化
res:=1@x;
//res值为2
```


例子2：
```
inc_sq:=
[
    result:=
    {
        a:=arguments:lvalue integral;
        a=$a+1;
        value:=$a*$a;
    }.value
];
a:=allocate integer=114514;
res:=a@inc_sq;
//res为114515*114515，a为114515
```
