语法：`[Expr]`+`if`+`[rvalue-Boolean-Expr]`(+`else`+`[Expr]`)?
若 `[Boolean-Expr]` 为真时计算第一个 `[Expr]` 作为表达式的值，否则计算第二个 `[Expr]` （如果有的话）或空值（`()`）作为表达式的值
语言保证对于两个表达式只会计算其一的值。
`else`永远与最近的`if`结合。

例子：
```
a:=114514 if true else 1919810
//a 是 114514
b:=
114 if a==1919810
else 514 if a~=114514
else 1919810
//b 是 1919810
```
