一个对象的形状，是指这个对象持有的所有属性以及属性的形状的总和。

```
{a:=1;b:="123123"}
{a:=2,b:="......"} //具有同样的形状
{a:=2,b:="aaa"} //具有不同的形状，因为b的形状是 3*(32@integer)
```

一个形状可以被用作对于值的约束。

形状之间可以进行算数运算。

```
({a:=1}@shape)|({b:=1}@shape)

({a:=1}@shape)*20
//or
20*({a:=1}@shape) //值是一个数组的形状，包含连续的20个形状为 `{a:=1}@shape` 的元素
