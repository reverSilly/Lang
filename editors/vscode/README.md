# Lang VS Code Extension

Lightweight syntax highlighting and editor configuration for `.lang` files (Layer 0 & Layer 1).

## Local Install

Symlink this folder into your VS Code extensions directory and reload the window (`Developer: Reload Window`):

```bash
ln -s "$(pwd)/editors/vscode" ~/.vscode/extensions/lang-syntax
```

For WSL / Remote-WSL, run the same command inside WSL (for `~/.vscode-server/extensions/lang-syntax`) or copy/link into your Windows `%USERPROFILE%\.vscode\extensions\lang-syntax`.
